## How to Register on MSG91:
1. Go to MSG91 Dashboard → WhatsApp → Templates
2. Create new template with name `nevika_cura_membership`
3. Category: **Utility**
4. Language: **English**
5. Copy the body text above (with {{1}}-{{5}} placeholders)
6. Submit for approval (takes ~24 hours)

---

## Note:
- The 16-digit membership code is NOT included in the WhatsApp message (sent via email only for security)
- The WhatsApp message confirms the membership activation and lists benefits
- The email (sent via Resend) contains the actual 16-digit membership code
